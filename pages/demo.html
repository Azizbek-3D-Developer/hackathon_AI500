Project Description

1. What is being shown

This demo shows a working prototype of Hosilbor, a web-based platform where farmers and customers can trade agricultural products in one unified place. The video walks through the main user flows: navigating the marketplace, viewing available products, and understanding how farmers can publish their goods while customers browse and order them.

2. How it relates to the problem and our solution

The core problem addressed is the lack of a direct, efficient, and transparent marketplace connecting farmers with buyers. Farmers often struggle to find buyers quickly, leading to financial losses and food waste, while customers face inconsistent pricing and limited access to fresh products.

Our solution provides:

  • A centralized online marketplace
  • Direct communication between farmers and customers
  • Transparent product listings
  • Faster distribution and reduced spoilage
  • A scalable digital system for regional agricultural trade

The demo demonstrates how these problems are solved through a simple, intuitive, and accessible web interface.

3. Stack, technologies, and AI used

Our team built the main application using:

  • React.js – UI & component structure
  • Node.js / Express – backend logic and API
  • Gemini AI – powering features such as:
    • Smart product recommendations
    • Assistive queries for buyers and farmers

The /demo presentation website is built with:

  • HTML, CSS, JavaScript
  • Custom neon-dark theme
  • Responsive layout and demo viewer

This dedicated page serves as a standalone showcase of our hackathon project.

4. Roadmap stage and next steps

According to our 10-day roadmap, the project is currently at the MVP stage:

  • Core marketplace logic implemented
  • UI built
  • Backend integrated
  • Basic matching logic functional
  • Demo-ready deployment completed

Next steps:

  • Add user authentication and secure profiles
  • AI-powered demand forecasting
  • Real-time order tracking
  • Expand agricultural product categories
  • Mobile-friendly interface
  • Performance & scalability improvements
